=========================================
§ 96: Dividing a Segment in a Given Ratio
=========================================

.. folio:: 0074
   :page: 49

**96.** *Prob.* To divide :math:`MN` at :math:`P` into parts proportional to the two given distances :math:`PQ, RS` (fig. 40).

*Sol.* To :math:`PQ` add in a straight line :math:`QV` equal to :math:`RS` (§ 73).
To the three :math:`PV, MN, PQ` find the fourth proportional (§ 93), and place it upon :math:`MN` in :math:`MP`, which is done by subtracting it from :math:`MN` (§ 72). It will be done.

.. picture:: 0074.g1.png
   :alt: Archival Fig. 40 (folio 0074, p. 49): Dividing segment PQ in the ratio MP : PN

*Dem.* Since :math:`PV : MN :: PQ : MP`, it will also be :math:`PV : MN :: QV : PN` (V.5). Therefore :math:`PQ :`

.. folio:: 0075
   :page: 50

:math:`MP :: QV : PN`. Hence (V.16) :math:`PQ : QV :: MP : PN`; that is, :math:`PQ : RS :: MP : PN`.
