§ 96: Dividing a Segment in a Given Ratio¶

96. Prob. To divide \(MN\) at \(P\) into parts proportional to the two given distances \(PQ, RS\) (fig. 40).

Sol. To \(PQ\) add in a straight line \(QV\) equal to \(RS\) (§ 73). To the three \(PV, MN, PQ\) find the fourth proportional (§ 93), and place it upon \(MN\) in \(MP\), which is done by subtracting it from \(MN\) (§ 72). It will be done.

Dem. Since \(PV : MN :: PQ : MP\), it will also be \(PV : MN :: QV : PN\) (V.5). Therefore \(PQ :\)

\(MP :: QV : PN\). Hence (V.16) \(PQ : QV :: MP : PN\); that is, \(PQ : RS :: MP : PN\).
