Notes: Linear Distance Doubling¶

Symbolic Verification and Hexagonal Symmetries

SymPy Coordinate Verification¶

In Cartesian coordinates, let \(A = (0, 0)\) and \(B = (1, 0)\). Then:

\[C = \left(\frac{1}{2}, \frac{\sqrt{3}}{2}\right), \quad D = \left(-\frac{1}{2}, \frac{\sqrt{3}}{2}\right), \quad E = (-1, 0).\]

The distance from \(B\) to \(E\) is \(2\), and the vector \(\vec{AE} = (-1, 0) - (0, 0) = -1 \cdot \vec{AB}\). The library implementation in geometor.mascheroni.collinear_doubling() verifies:

import sympy as sp
        from geometor.mascheroni import collinear_doubling

        a = sp.Point2D(0, 0)
        b = sp.Point2D(1, 0)
        e = collinear_doubling(a, b)
        assert e == sp.Point2D(-1, 0)
        assert b.distance(e) == 2 * a.distance(b)

Significance in Compass Geometry¶

Collinear doubling is the arithmetic engine of compass geometry. Because straight lines cannot be prolonged with a ruler, linear extension is accomplished by stepping along circumferences. By repeating § 64, any integer multiple \(k \cdot AB\) is constructed along the ray.
